# Nexus 产品边界

Nexus 是建立在 Grok Build runtime 之上的独立品牌发行层。目标是在不重命名、fork 每个
内部 Rust crate 的前提下，将上游运行时变成私有、多模型提供商的编码代理。

```text
开发者
    │  nexus / nexus plan / nexus review
    ▼
Nexus 中文命令层
    ├── ~/.nexus 状态、会话、配置、技能与授权
    ├── 模型预设（OpenAI 兼容 / Messages / 本地）
    └── 隐私与 workspace sandbox 默认值
    ▼
Nexus 品牌二进制（nexus-agent）
    ▼
上游代理运行时
    ├── TUI 与 headless/ACP 模式
    ├── 文件、终端、搜索、Git、worktree 与 MCP 工具
    ├── 计划模式、授权、hooks、skills 与子代理
    └── 已配置的模型端点
```

## 有意保留的兼容边界

当前 runtime 内部读取 `GROK_HOME` 等变量。Nexus 包装器仅为其子进程设置这些变量，并将
它们指向 `~/.nexus`。这会隔离用户原有 Grok 安装的状态，同时保持上游 crates 不变，也让
安全修复更容易同步。

这个边界被明确记录而非隐藏。只有在上游 runtime 能被整体重命名并经过完整发布测试后，才应
以原生 `NEXUS_*` 配置替代它。

## 默认值

| 关注点 | Nexus 默认值 | 原因 |
| --- | --- | --- |
| 模型访问 | BYOK / 仅本地 | 不绑定账号，也不在仓库保存密钥 |
| 状态 | `~/.nexus` | 与上游及其他代理工具隔离 |
| 遥测与追踪上传 | 关闭 | 本地优先 |
| 自动更新 | 关闭 | 源码受控、构建可复现 |
| 沙箱 | `workspace` | 正常项目工作，不授予宽泛写入权限 |
| 授权焦点 | 仅允许一次 | 防止意外长期授权 |
| 模型目录拉取 | 关闭 | 避免启动时无关的网络请求 |

## 后续方向

当前版本是可用的终端产品。桌面界面、签名安装包、模型提供商健康检查和项目级策略编辑器是
自然的后续方向，但应在 CLI 的构建流水线稳定后再加入。
